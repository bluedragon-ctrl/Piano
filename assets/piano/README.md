# Piano samples

16 Ogg files (about 1.4 MB): the "Splendid Grand Piano" Steinway samples at
mezzo-forte velocity for C4–B5. The sample set was released into the public
domain by Akai and converted by the
[sfzinstruments](https://github.com/sfzinstruments/SplendidGrandPiano) project.
Fetched from the smplr sample host, unmodified.

File names are case-sensitive and match what smplr requests (note the `MF` /
`Mf` difference); do not rename them. Only Ogg is bundled, so playback relies on
a browser with Ogg support (Chrome, Edge, Firefox).
